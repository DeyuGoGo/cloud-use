# 《約跑團 Run With Me》

一個普通上班族，被夜跑團真心接住。當他在合照裡越站越中間，可以好好說話的人卻慢慢變少了。

成人向單機敘事遊戲，Godot 4.6.3。新版採 **漫畫分頁＋場景互動＋Alive 手機敘事**。

## 目前版本：M1〈第一晚，真的被接住〉

2026-09-11 更新漫畫節奏與主角外觀。從下班、堤防、第一次入團到超商散場與回家訊息，是一段完整可玩的第一晚。

- 120 個來源段落合成每路 **70 頁**；一頁一至四格，日常動作由畫面承接。可見正文與分格短句約 630–650 漢字，比前版少約七成。
- 新增七套四格分鏡，立翔依既有合照建立固定設定圖，統一臉型、黑髮、細框眼鏡、灰跑衣與白襯衫；自己的頭像同步改正。
- 三處具體選擇、八種組合；與 Jason 的相處、選過的合照，都會在後面的話裡被記住。
- 新標題、場景／對話演出、空位與飲料互動、合照選圖、手機訊息、閱讀紀錄、暫停與聲音。
- 跑步紀錄、集合邀請、入團前的舊貼文與合照預覽用畫面呈現；照片出現後只留人物的短反應。
- 手機恢復 Alive 的紫黑動態牆與私訊風格；能放大照片、瀏覽已收到的訊息、按讚與收藏，社群偏好跟著存檔。
- 跑後紀錄有可重用的路線與成績版型；坐下、接水各只留一個互動，透過前後鏡頭看見視角和水瓶的變化。
- 新版獨立存檔並帶備份；舊版 `run_save.json` 保留。
- 全劇與角色已修訂；後續章節仍為綱要，尚未製成遊戲。

## 開始玩

雙擊 [開始遊戲.bat](開始遊戲.bat)，或用 Godot 4.6.3 開 `game/project.godot` 後按 F5。啟動檔會先檢查並匯入素材，需要幾秒鐘。

換一台電腦時，可把 Godot 執行檔拖到啟動檔上，或設定 `GODOT_EXE` 為完整執行檔路徑。詳細步驟見 [換機接手筆記](11-換機接手.md)。

「開始這個晚上」開新進度；推進第一段後會保存新版進度。「繼續這個晚上」讀回上次的位置。新遊戲尚未推進就離開，不會覆寫先前的新版進度。

操作：滑鼠點擊，或空白鍵／Enter 推進；第一次按可顯示全文。Tab 移至選項，空白鍵／Enter 確認。Esc 暫停，L 開閱讀紀錄，M 開關聲音。互動無限時，不需每段左右滑。

## 故事新基準

核心是「每一步，他都有一個自己相信的理由」。允許人物自我合理化，同時分清合理界線、疏忽與刻意利用。小團先有值得留下的生活，女性有自己的目標與拒絕。第四章保留公共事件，第六章改為團內協調與個別退出；〈接住〉和〈跑嗎〉有平等完整的尾聲。

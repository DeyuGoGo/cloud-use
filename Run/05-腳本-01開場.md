## 這次要讓玩家經歷什麼

立翔只是想去看看。他原本不認識跑團的人，到了卻遇見同事；Ray 讓他跟得上，Ann 留個位子，河邊見過的女生這次跟他說上話。回家時，有人約了下一次。

先讓話接得起來、人待得下來。不要每拍都安排笑點，也不要讓每個人輪流替他解圍、送東西、證明他被看見。有人顧著吃，有人先走，聊天不必全都圍著新人。

## 範圍與文字長度

- 保留 120 個來源 ID 及順序；每條完整路線仍經過 112 個來源拍，合併為 **70 頁**，比前版少 42 次推進（37.5%）。來源拍數不再等於翻頁次數。
- 三處雙選、共八種組合，所有路線完成第一次夜跑。when 與 choice value 保留原契約。
- 本輪單路可見正文與分格短句共 **632–646 個漢字／844–859 字元**。相同口徑的前版為 **2,366–2,382 個漢字／2,947–2,969 字元**；逐路比較，漢字減少 72.9–73.3%，字元減少 71.0–71.4%。
- 計數逐路套用 when：普通頁計 text，漫畫頁只計 comic.panels[].text；comic_parent 不另計。字元包含標點、拉丁文字、空格與訊息換行，不含說話者標籤、選項、action、分鏡標題、alt、視覺卡片內文字與介面文字；前後使用同一口徑。
- 不用補字或強制等待湊滿原先的 15–20 分鐘估時。較短文字與新增圖像的實際節奏，以新版遊玩再確認。
- 每頁由玩家前進；一頁漫畫一次顯示全格，成員來源拍不另停。畫面可無正文，不能為了保留 ID 再替圖片加一段解說。
- 本版止於回家關燈；下一章、日常經營、精力與關係數值不在本輪內容內。

## 人物聲音與生活細節

- **立翔**：開始回答比較短，熟一點才主動問。自言自語可以有半句，不必每句都自嘲或宣布寂寞。

- **Ann**：大方、直接，遞一瓶水不用繞三拍優惠與發票。她也休息、吃自己的東西；回家只接一句謝謝，便去洗澡，明早另有安排。

參照《女二》出版社試閱的散場聚會，調整的是誰在忙、誰坐在旁邊、話如何被眼前動作帶走；參照《我們（還在初戀的島上）》公開節選，讓回話接住對方已說的事，訊息承接既有相處。葉揚與彼得的採訪、作家公開對談則提供短反駁與省略共同前文的觀察；這些是經編輯的生活回述或對談，不是私人聊天的原始逐字紀錄。

## 可執行文本慣例

- 頂層保留 title、version: 1、beats。
- 每拍保留唯一 id、scene、time、bg、cast、kind、speaker、text；潤稿不重排 ID。
- kind: phone 的拍使用 cast: [] 與 thread；離開手機明確回到 scene。Alive 照片拍呈現貼文，其餘為相應收件人的私訊；短行保留在 text 內，不新增短拍。
- choices 的 label 可隨文案調整，value 為存檔契約，不隨字面更名。相同的「這張」靠實際圖片與對應按鈕辨認。
- when 只參考之前的 choice/value；本輪原樣保留。
- action 為具體的前進動作，不是另一個隱藏分支。store_04 為「接過水」，end_yijun 為「替手錶充電」。
- visual 為單拍畫面，不沿用到下一拍。相對應的 text 可空白；閱讀紀錄應用畫面標籤標記。
- 漫畫 anchor 加 comic：atlas 為圖集資源路徑，title 為短場景名，panels 指定 frame、speaker、text、alt；through 是同頁最後一個來源 ID（含該拍）。預設 grid: [2, 2]，frame 0／1／2／3 對應左上／右上／左下／右下；既有單張圖指定 grid: [1, 1]。一頁可選 1–4 格，選單格也可取四格圖集中的任一格。
- anchor 之後至 through 的來源拍加 comic_parent: anchor ID，保留來源順序。合併必須相鄰且 when 完全相同，不跨 choices、phone、visual、未移除的 action，或 store_02／03／04／05 四個互動與結果拍。
- 漫畫頁一次顯示全部格，短句完整顯示；來源 text 留空，不再重複顯示或累計。回看紀錄列 comic.title 與各格 alt，並將整頁來源標為已讀；舊存檔若停在成員拍，回到其 anchor 閱讀整頁。
- office_08、before_11、home_02 的原 action 已由分鏡承擔並移除，其他保留的 action 仍依原流程執行。跨時間漫畫用 anchor.time 顯示時段，避免把下班到出門誤看成同一分鐘。
- 有旁白混入對話時，改用旁白承載引號內的話，不讓角色念出「她指了……」。

## 本輪驗收

1. 八種組合各經過 112 個來源拍、顯示 70 頁；120 ID、順序、when、choice value 與前版一致，八個 visual 定義保留。
2. JSON 與潤稿本的 text、speaker、label、action、漫畫分格及併頁範圍一致。可見文字只計正常頁 text 與分格 text，不重複計成員或 alt。
3. 怡君沒有馬尾、頭燈或頭燈回收；Jason 衣色、Ray 帽子、背包領回及衣服時間正確。
4. 字稿不再描述合照的構圖與笑點；舊團照與當晚合照不混用。before_05 收藏的是集合資訊；home_01 漫畫頁由 Alive 標註通知進入當晚貼文，所有 phone 內容保留。
5. 漫畫頁一次展示全格，只前進一次；舊成員存檔可回 anchor，回看不重複列來源正文。坐下、接水各有一次操作與獨立結果，不被併頁略過。
6. 逐頁核對畫面與接話：人物的動作、所在位置與時間符合該格，不用已經發生過的圖代替下一個動作。文字是否自然、留白是否足夠由讀稿與試玩判斷；資料測試只驗證流程和契約。

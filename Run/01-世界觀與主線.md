# 01 — 世界觀與主線

> **敘事基準｜2026-09-10，M1**
> 本文件是後續製作採用的全劇骨架。M1 只實作序章〈那盞燈〉；第一章以後尚待製作，不能當作遊戲完成清單。人物以 [02-角色](02-角色.md) 為準，取捨見 [M1 劇情修訂紀錄](Design/M1-劇情修訂紀錄.md)。

## 這是個什麼樣的地方

台北的夜跑團。有人想練跑，有人不想下班就回家，有人想交朋友、談戀愛，有人只是被同事拖來。跑步、合照、超商前不知道什麼時候才散的聊天，把原本互不相識的人放在一起。

**一開始，它是真的好。** Ray 記得新人的名字，Ann 多買一瓶水，有人把腳邊的包移開，讓你坐下。這些舉動就是善意；後來發生的事不能把第一晚全部改判成手法。

團變大之後，人數、工作量、期待一起增加。有人靠分工應付，有人開始依賴少數人的付出，有人把受歡迎誤認成親近。環境給人壓力，人仍要為自己的做法負責；故事不預言所有社群最後都會腐敗。

素材取自都會社交路跑的生活情境。人物、媒體、事件及因果均作虛構處理，不把遊戲中的醜聞寫成任何真實團體或人物的紀錄。

## 核心問題：我想被留下，也得容許別人離開

立翔嫌麻煩，也不甘心每個星期都一樣。他想認識人、談戀愛，想把跑步練得輕鬆一點，也會比較同事的升遷。跑團讓下班有了新的去處；有人開始找他做決定，他發現自己也想試試安排別人的一晚。被喜歡、把事辦好與說了算，漸漸混在一起。

故事追的是：**一個人如何從享受關係，走到習慣別人隨時為自己留位置；又如何承認，那個位置不是自己永遠應得的。**

這是立翔的敘事線。其他人各有想過的生活：Ray 想辦出有自己特色的活動，Ann 想吃好、約會與出遊，Jason 想升遷又不肯承認自己很在意，凱文想讓今晚多一點新鮮事，怡君想把輪班之外的時間留給跑步與接力。團體的摩擦也來自這些願望碰在一起；一次聚會不用先有人受傷，才值得演。

- **理由不是判決。**「我很累」「我怕失去機會」「我只是隨口說」可以解釋行為，不能免除違約、轉述私事或利用職務的影響。「我又沒做錯」是立翔可能說給自己聽的話，不是作者的裁定。
- **界線可以帶來好結果。** 拒絕額外工作、婉拒邀約、拒絕親密、晚點回訊息，都能被理解。對方失望也不等於主角有罪；需要檢查的是有沒有答應、有沒有告知，是否長期把同一個人當作必然會等的人。
- **傷害落在具體行為。** 單次漏回、沒有帶飲料、沒有戀愛感覺，不足以證明一個人有罪。答應刪照卻繼續宣傳、答應交接卻消失、未經同意轉交私訊，才各有可辨識的責任。
- **補救不等於求赦免。** 道歉可以被接受、被拒絕或暫時沒有回答。處理完該做的事，人也不必重新喜歡你；關係能結束得比較清楚，已經是結果。
- **沒有天生壞人，也沒有不能犯錯的好人。** 不用替人物洗白、替玩家找罪，或安排一個無瑕的人代作者審判大家。

## 呈現方式：跟人一起待過，才感覺得到少了什麼

以 2D 場景式敘事為主。對話的分量來自誰先靠近、誰在等、誰已走出畫面；手機讓玩家看到現場之外仍在繼續的生活。一般對話直接閱讀，決定去留、答應或公開什麼時，才做行動選擇。

- 回訪同一張超商桌、同一段堤防、同一個聊天室。前期有人替立翔挪位子；後期可能輪到他挪，也可能他回頭時對方已經走了。
- 保留繫第二次的鞋帶、沒送出的半句話、開飲料的停頓；不在動作後補「這代表他害怕被丟下」。
- 手機呈現約定、照片、近況與延遲回應，不一直用通知打斷現場。人物也會下班、看病、找朋友，沒有回覆不必全都與立翔有關。
- 選項後留下完整反應。回收玩家實際做過的事，不製造沒做過的惡意、不把溫暖選項偷偷翻成傷害。
- 前半要有沒有伏筆任務的閒聊、笑話與相處。第一晚不是犯罪證據的預先蒐集。

## 貫穿物件

### 玄關的那盞燈

- **序章**：出門前留著小燈，回來帶著一點不同的精神；先不交代他究竟在等誰。
- **第二章**：回家先看群組的新照片。燈在畫面裡，他沒有抬頭。
- **第三～五章**：有時忙到忘記關，有時因為已約好有人來而特意留下。相同動作可以有不同原因，不做墮落計分。
- **第六章**：安靜的客廳裡，他先做完說好要處理的事，再放下手機；燈不替他宣布自省完成。
- **〈接住〉尾聲**：他提早回家，把燈打開，吃完還熱的晚餐。今晚沒人要來，也過得下去。
- **〈跑嗎〉尾聲**：出門前關燈。不是戒掉需要別人，而是今晚只打算跑步，不必替尚未發生的相遇準備一整個晚上。

遊戲內不解釋象徵。兩個結局都容許他繼續想念別人、需要朋友。

### 飲料與合照

Ann 多買的那瓶水、老周順手帶的美式，保留為日常往來。當事人可以說「今天自己買喔」，另一個人自然答「好」。少買一杯不必一律拍成背叛。

合照同時是回憶與團務。拍照的人也會被叫回來入鏡；後來的問題在於誰決定用途、退出者是否仍被當宣傳素材，不是站中間就等於變壞。

## 親密關係與成人內容

成年人的情慾可以溫暖、好玩、笨拙，也可以互相誤解。性不是墮落進度條，沒有性也不代表關係比較高尚。

- 維持暗示與淡出。分量在於前後怎麼說明期待、怎麼聽見拒絕、隔天有沒有承認彼此。
- Ann 與立翔可以發展為雙方同意的成人支線，也能維持朋友。她的主線、界線與後續生活不依賴玩家是否進支線。
- 怡君與凱文不是情侶。她可以享受相處，也可以因期待改變而結束，不必受辱後才有離開的資格。
- 第五章立翔與怡君可以彼此願意地親密，也可以只聊一晚。兩版都保留她的睡眠、工作安排與對相處的要求；後續取決於是否聽進要求。
- 郁婷不靠隱藏職業或床上取材推動報導，不設必經親密場景。Wendy 保留為職場人物，本輪取消她的必經成人場景。第六章不安排匿名女生作為男主麻木的示範品。
- 不用目擊別人的性行為當章尾揭密。別人有約會、戀愛或性生活，本身不是給主角的背叛。

## 兩次危機的決定

**第四章保留一次公共事件；第六章改為團內協調與個別退出，不再出現第二篇全民渣男審判。**

第四章有當事人、現場經過及需要處理的活動安全。郁婷不以床上轉述的一句狠話炸毀 Ray；第六章也不拿女生們的私生活拼出對稱報應。兩次危機共享「沒有及時聽人說話」的可能原因，但規模、責任與解法不同。

## 白天線

公司是立翔觀察自己需求的另一個地方。老周以前罩過他，Wendy 分派工作，Jason 擅長在會議裡被記住。白天不只是教他學壞的練習場。

第一章先演一次有效界線：立翔說明今晚不能順手對完老周的報表，指出一欄要再查；老周自己處理，隔天仍問他跑得如何。後面再放進另一種問題：有些工作真的輪到他負責；若他答應卻悄悄留給別人，就會被要求補做。是否幫忙與是否履行已承諾的事，要分開。

Wendy 可以認可合理排程，也可能為自己的壓力催進度。Jason 可以搶發言，也能把立翔的名字補進簡報。人不是固定發出同一種傷害的裝置。

## 全劇逐章骨架

各章須回答：人物想要什麼、實際做了什麼、哪段關係與開頭不同。以下是製作骨架，不要求擴成更多系統。

### 0.〈那盞燈〉— M1

**立翔要什麼**：過完普通的下班夜晚。他未必承認想認識人，只是決定週五出去看看。

**場面**：週二下班、河堤與短髮女生互相招呼 → 入團前幾天 → 集合處遇見 Jason、Ray、Ann → 跑途中認識凱文，與怡君說上話 → 跑後超商 → 回家手機。保留對跑團的防備、撞見同事的尷尬、有人挪出一個位子，以及第一次被叫對名字。暖意後不必補可疑眼神。

**行動與回訪**：少量明確行動與三處雙選決定怎麼加入相處，後段以台詞或照片回應。兩邊都能遇到真誠反應；沒有固定善惡，也不把怡君不入鏡寫成掃興。M1 的具體文字、選項與畫面以當次序章腳本及遊戲實作為準。

**關係與收束**：從「我只是路過」到手機裡有一個能辨認的人。回家仍是一個人，但第一晚有一件值得記住的小事。本段完整，沒有炎上預告或道德扣分。

### 1.〈下次見〉

**人物要什麼**：立翔想再見到那些人；Ray 想把自己排的路線與拍照安排做順；怡君想留住輪班之外準時的跑步；Ann 想吃完熱的晚餐，再決定要不要多坐一下。

**場面**：
1. 白天立翔跟老周說明下班時間；合理婉拒被正常接受。
2. 回到超商，有人記得第一晚的選擇。他也能替剛到的人挪位子。
3. Ray 問他願不願意偶爾整理合照。答應只從一晚開始；不答應則換人輪值，他仍被叫回照片裡。
4. Ann 的餐到了，Ray 還在弄照片。她先吃，不等每個人都忙完；收桌時請旁邊的人順手幫忙。怡君因同事來電提早走，約下次跑的人把日期說清楚。

**關係變化**：從被招呼的新人變成有名字、有小約定的熟人。有人先吃、有人早走，剩下的人繼續聊；章尾是一個真的想去的下次邀約。

### 2.〈有人找我〉

**人物要什麼**：立翔喜歡有人主動找，也想自己挑一次要赴哪個約；Ann 想跟立翔吃一頓飯，看看兩人單獨相處如何；凱文想把臨時多出來的好玩安排也接住，開始碰到同時答應的約。

**場面**：
1. 團員要照片、Jason 要帶同事來、Ray 問能否多幫一晚，私訊第一次多到來不及回。
2. 既有約定碰到臨時邀請。守約、事先改約都能有好內容；若答應後消失，下次由當事人指出具體那一晚。
3. Ann 主動約一頓不用她張羅的晚餐，說明期待，也拒絕臨時加上的團務。成人支線只在雙方願意時發生。
4. 凱文想多去一攤，怡君說今天跑完就回家。他才發現另一邊也等著自己，得取消已接下的一個約，處理對方已經空出時間這件事。

**關係變化**：立翔開始需要回應期待。朋友與親密對象的需求可以不同，不能用「我們很熟」替對方決定可以等多久。

### 3.〈擠一點〉

**人物要什麼**：Ray 想保留大家認得的集合點與合照，認為自己在現場還能處理；立翔想把團務做得更有效率，享受意見有人聽；Ann 不想每次為等人而延後吃飯與原本的約；郁婷想完成公共空間採訪，也想保有跑友身分。

**場面**：
1. 集合點坐不下。跑友與路人都需要通過，Ray 先移開隊伍，稍後又因趕合照拖延重新分組。
2. 管理群討論改線與人數。Ray 說「這週先照原來的，下週再調」。不是撞人無所謂的宣言，但確實是他作出的延後決定。
3. 郁婷公開自己的記者工作，提出正式採訪。私人聊天不能直接當可刊引語；立翔可以提供自己負責的資訊，不能代別人同意。
4. Ann 交回宵夜接龍，跟 Jason 去吃她原本就想吃的店。立翔失落；Ann 不需為沒把每晚留給他辯解。
5. 怡君工作後想聊兩句。立翔忙，可以明說並另約；若慣常敷衍，她下一次先找別人。少一段聊天，不等於她的人生停止。

**關係變化**：「大家會互相幫忙」開始需要明確分工。忙碌、想贏與自我合理化有誘惑力，人物也能選另一種做法。

### 4.〈那通電話〉— 公共事件與分流

**事件定稿**：一場人多的夜跑中，隊伍堵住行人動線，一名路人被碰倒。現場有人停下協助，也有人沒看見就繼續跟跑。路人的經驗與現場影片被公開。

**人物要什麼**：受影響者要被認真回應與避免再發生；Ray 想維持活動，又必須承認延後調整的責任；立翔想保住歸屬與名聲；郁婷要把經過查清楚。

**場面**：
1. 現場先處理人，群組晚一點才出現不同版本。
2. 郁婷以當事人敘述、現場影像、可核對的安排及正式回應成稿。不確定的部分保留，不以偷來的床邊話作核心引號。
3. Ray 起先想說「造成觀感不佳」，聽過當事人的要求後才重寫。立翔能陪同處理；若因工作不能到場，可以交代掌握的資訊與能做的部分。
4. Ray 當晚打來，問：「今晚超商……你還會去嗎？」這仍是情感中心，但接通不等於替他辯護，沒接到也不是壞結局開關。
5. 隔天確認分工，Ray 暫停大型活動。立翔選擇**承擔有限的收尾工作後退出擴張**，或**接任縮編試行團的協調人**。分流由這個清楚行動完成；電話當下的做法影響談話距離。

**關係變化**：Ray 習慣在現場說了算，這次需要把自己的決定與他人的處理方式一起放到桌上。立翔能幫忙，也可能不同意他仍想保留的安排；兩人的關係不靠公開私生活證明義氣。

#### 結局〈接住〉：第四章之後的完整尾聲

用三場不同時間的戲完成這種生活選擇，不以分流後立即切黑交付。

1. **幾天後，收尾**：在約好的時間，兩人交完已答應的回覆、物品與資料。Ray 承認自己的決策；立翔只認自己真的做過的部分。有人願意再談，有人不回來。
2. **幾週後，小團**：少幾個人不等於氣氛自動恢復。Ann 這晚有自己的安排，輪值的人買飲料；Ray 嫌這次的歌不好聽，仍坐著吃完便當，沒有接回音響。立翔準時說要走，大家正常道別。
3. **回家**：工作仍要做，老周有自己的生活，怡君依班表約下一次。立翔沒有換得永久的中心位置。他開燈、吃晚餐，回完一個答應要回的訊息。

**獲得與代價**：學會陪人承擔而不替對方包辦，關係不用靠無限付出維持。代價是放下這次繼續做大活動的機會與想像，不是失去升遷、戀愛或所有未來。

### 5.〈輪到我安排〉— 選擇接任後

**人物要什麼**：立翔想證明團能變好，也喜歡被問「你決定」；新團員晉安想用有限下班時間穩定練半馬；怡君要正常輪班、睡覺與跑步；小柔想交朋友，但不想出現在宣傳照裡。

**場面**：
1. 接任有談話與責任清單，不是 Ray 倒下後大家神祕地把他推上去。先接六週試行，期末回顧是否續任；立翔可以對人數、工作量設限。
2. 晉安主動做路線表，做得太細，讓只想輕鬆跑的人有壓力；他也需要問別人要不要。
3. 小柔要求不要公開近照，也不要因不參加續攤就一直追問。立翔具體處理照片及邀請方式；履行會留下信任，拖延會留下可指出的未完成事項。
4. 怡君與立翔聊一晚，各自說一段工作的事。可以親密，也可以止於聊天；她說清哪幾天不能臨時找。她的界線在下一場確實影響他能不能見到她。
5. Ann 拒絕恢復每週代訂與墊款，跟其他朋友參加短程活動。立翔得輪值補缺，不能靠「姊最會照顧人」把工作塞回去。

**關係變化**：立翔是否聽人說話，能在安排上被看見。做得好，團真的改善一些；忽略要求，問題在於略過當事人的選擇，不在於他受歡迎或有性生活。

### 6.〈有人先走〉— 團內協調與退出

**不製作第二次公共炎上。** 沒有五個女生的私訊拼圖、純潔新人代發判決，或怡君因感情受挫按下毀滅開關。

**人物要什麼**：各人把還願意投入的時間說清楚。立翔想留住大家，必須分辨能修補的工作與不能要求別人繼續的關係。

**場面**：
1. 晉安想用出席表解決缺工，小柔拒絕向全團交代不能來的理由。他先不高興，後來承認把「方便管理」放得太前面，撤掉欄位。新人也要調整。
2. 輪值會議由當事人談自己的事。只回收真的發生過的未刪照片、失約交接；玩家已處理的事，當事人會承認。私人戀愛與床事不供全團評分。
3. 怡君另約能談清楚的時間。若立翔持續敷衍，她停止臨時陪聊與親密；若他尊重界線，她仍願意往來，只是班表與訓練目標改了。留下或離開都不是道德獎懲。
4. 凱文另約想去的新路段，怡君把時間留給接力練習，Ann 照自己的行程出遊，也有人願意再試。這些都能在既有的告別與訊息場面交代。立翔不能靠「下次改」把所有人留在同一張桌；即使善待大家，團體也不會永久維持原樣。
5. 六週試行到期，立翔完成修正與交接，決定不續任。若前段問題多，這是停止繼續靠承諾拖住大家；若前段運作順利，這是把已有分工交出去，留回自己的時間。留下的人採小組輪值試行，不自動由晉安繼位；之後成敗不作宿命預告。

**關係變化**：若傷過人，必須處理，不能用「大家本來就會散」卸責；若沒有傷害，也不強迫寫成罪有應得。兩種情況都面對：人可以離開，而他不必把離開翻譯成自己毫無價值。

### 7.〈跑嗎〉— 完整尾聲

三場有時間間隔的戲，讓 Ray 保有選擇。並肩一段不是原諒證書。

1. **交還物品**：交回擴音器、團務資料等約好的東西。若第四章曾晾下 Ray 或卸責，在此說清那一件，不附「我也有壓力」要求理解；若當時已有正常交代，就談各自的接任與退出，不捏造舊罪。Ray 只說現在不想再談跑團，也不接受當晚邀約。
2. **隔一段日子，遠遠遇見**：堤防看到 Ray 和老吳，第一次只點頭，立翔繼續跑自己的。該完成的工作已做完，沒有天天訊息催 Ray 回應。
3. **另一個普通晚上**：立翔關燈出門，又遇到兩人。老吳問「跑嗎？」Ray 繫好鞋帶，自己補一句「我今天只跑到橋下」。立翔跟上。到橋下 Ray 說先走，他不追問下次，也不擅自把三人照片發群組。

**獲得**：仍想被接住，但不先替每次相遇安排永久的意思。Ann、怡君等人依先前生活延續，不必同框證明男主值得被愛。其他跑團繼續有人笑、有人加入，不拍成永遠吃人的機器。

## 兩個結局的製作規則

- 遊戲、存檔、選單與宣傳只使用 **〈接住〉、〈跑嗎〉**，不設真／普通／好／壞等級，不稱較長路線為完整真相。
- 〈接住〉處理「怎麼陪人、怎麼有限度留下」；〈跑嗎〉處理「怎麼結束一個位置、接受別人只同行一段」。
- 每條結局都有收尾工作、關係的新距離與可過下去的生活。片尾不提示選錯、未完成主題或錯過真正結局。
- 具體行動影響信任與對話。單次沒接電話、是否上床、是否分享照片，不單獨決定人格與結局。

## 寫作語氣與製作檢查

保留有點好笑、有點尷尬的尖點：Jason 嫌完仍補集合地點；凱文聊到新路段，忘了剛才說過今晚要早走；Ann 點完才發現大家根本沒聽她問吃什麼；Ray 又想改輪值的人選的歌。趣味與摩擦使用既有場景帶出，不增加支線，也不要求每次都以認錯、療癒或學會拒絕收場。

每個重要女性角色至少有一個自己提出的要求、一個可執行的拒絕，以及一件立翔不在場也會繼續的事。男性也有不服務主角成長的生活。這些要進場面與時間安排，不能只放角色表。

交付章節前檢查：
1. 人物說自己有理由，畫面是否仍容得下另一人的經驗？
2. 玩家若清楚拒絕或履約，劇本是否承認，而非照樣判他冷酷？
3. 是否有一件普通好事，不需要後來拆成算計？
4. 親密與拒絕是否都有當事人意願，沒有拿性替代人格？
5. 回收的對話、照片與承諾，是否真的是這一輪做過的？
6. 能不能少一段解釋，改由時間、動作和下次相處說出來？

### 語氣範例：同一杯咖啡，可以有不同原因

> 立翔下班前傳檔給老周：「今天我得先走。第三欄還沒對，你明天早上才要用，對吧？」
>
> 老周瞄了時間：「嗯，你去。鞋都換好了還裝忙。」
>
> 隔天桌上沒咖啡。立翔站了一下，老周從螢幕後探頭：「樓下機器壞了。跑得怎樣？」

這一場界線被接受了。之後若寫疏離，就讓它有自己的經過，不拿一杯咖啡替所有合理拒絕判刑。

> 另一晚，立翔答應幫忙的最後一頁還空著。老周問一次，他說快了；到家又忘了。
>
> 隔天老周已做完，立翔問要不要幫他買咖啡。
>
> 「不用。下次做不完，先講。」老周關掉檔案，空出桌面讓他把椅子拉過來。

這裡有人失約，也有人說清楚。還沒修好，也還沒有非得散掉。

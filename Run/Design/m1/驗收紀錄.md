## 實玩回饋後的劇本與演出修訂

第一次試玩指出怡君馬尾、耳機廣告與「想紅的網紅仔」不成立，且全段說明多於相處。這表示原先技術檢查與編輯閱讀不足以代替實玩。第二輪逐拍重修 120 段，刪除刻意笑點、孤獨解說、優惠發票與輪流送食物；改為人物之間能接續的短句與動作。

怡君依實圖固定耳下短髮、無頭燈；Ray 戴帽。瓶裝水、背包、晾衣時間、IG／LINE 來源與施工區外的集合點重新核對。四段純圖片拍無正文；三段照片反應只留一句話。兩個照片選項都用「這張」，用按鈕對應位置選取，程式以 choice_value 區分，沒有依賴重複標籤定位。

新增畫面層使用後即清除；回到人物場景、手機、結尾與暫停不留殘影或失去焦點。無字拍可一次前進並保存，閱讀紀錄留畫面名稱。拍序、when 與選擇 value 已和本輪修改前快照比較，完全一致；沿用原 M1 存檔。合照、群組圖片使用既有照片；新增舊團照不含尚未入團的主角。

參考當代台灣愛情／情慾書寫的訪談與對談，來源與本案判斷分列於 [台灣日常與敘事修訂參考](台灣日常與敘事修訂參考.md)，未仿寫單一作者。再次完整讀稿後，修正了仍在施工卻約橋下的問題；目前沒有已知阻擋試玩的接話或連戲問題。

## Alive 與第二輪實讀

依追加回饋，手機恢復舊 Alive 的窄版、紫黑底、紫粉頭像圈與貼文動作列。動態牆／收件匣／私訊共用一個手機，照片可放大；Ray 說「傳了」後直接附上玩家所選合照。團體帳號使用原生圓標，未入團的主角不會被借作團頭像。

按讚、收藏保存於 v1 的選用 social 欄位，與游標分開；舊存檔不具備此欄位仍可續讀。瀏覽只建立 visited 內容，不洩露未選照片與未到達訊息；在其他分頁按前進會先返回當前閱讀。放大照片時背景焦點停用，Esc 先收圖。流程測試涵蓋實際按鍵、社群保存／重讀、捲動保留與附件出現時機，最後紀錄無腳本錯誤或資源洩漏警告。

補讀《女二》出版社試閱一、《我們（還在初戀的島上）》第十章公開節選，以及高翊峰×葉揚對談、葉揚×彼得生活採訪。參考文件記明實讀範圍與編輯紀錄的限制，沒有聲稱讀完整本書。26 拍修改集中於接前一句、短答、被事情打斷，以及不同收件人的訊息目的；沒有增加點擊。Alive 帳號、群聊邀請與被標註通知同步接好，集合資訊收藏與可自由收藏的合照分清。

120 個故事 ID、順序、when 及 choice value 與修訂前快照完全相同；閱讀稿與執行 JSON 同步。本輪技術與視覺檢查通過，台詞效果仍留給實玩判斷。

## 啟動與操作

雙擊 [開始遊戲.bat](../../開始遊戲.bat)。啟動檔支援第一個參數或 `GODOT_EXE` 指定 Godot；未指定時先找本機既有 `Tools/Godot463`，再找 PATH 中的 `godot.exe`／`godot4.exe`。也可直接在 Godot 4.6.3 開 [project.godot](../../game/project.godot) 後按 F5。啟動檔保持 ASCII 與 CRLF，避免先前 Windows 批次檔亂碼與斷行造成的命令錯誤。

滑鼠或 Space／Enter 推進，Tab 選取按鈕，Esc 暫停，L 開閱讀紀錄，M 開關聲音。新版存檔為 `first_evening_v1.json`，附備份；原 `run_save.json` 保留。重新開始在第一次推進後取代新版進度。

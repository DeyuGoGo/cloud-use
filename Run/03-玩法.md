# 03 — 新版敘事與互動

2026-09-10 M1 執行基準。舊左右滑卡規則已由場景式序章取代。

玩家跟著立翔經歷一個晚上。主線由作者安排，具體的相處、選圖與回覆交給玩家，後文記住這些小決定。

## M1 已實作

- 一般場面以畫面、人物站位、對白與動作推進，不強制每場二選一。
- 三處雙選：如何回 Jason、挑哪張合照、先回誰的邀約。八種組合都通向完整的序章收束。
- Jason 的選擇在超商回收；照片在回家訊息回收；回覆 Ray／怡君各有完整答覆與不同的收尾動作。
- 坐下、接水各只有一個場面入口。坐下換成較低且靠近的視角，接水讓瓶子進入主角手裡；結果直接呈現在下一拍，不做成同義的並列選項。
- 手機呈現真正收到的訊息和選過的照片。可開對話紀錄查看已經歷的內容。
- 跑步紀錄、集合邀請、舊團照及合照預覽用畫面帶過。文字只補當下反應，不替圖片逐項解說。
- 跑後紀錄沿用同一版型，用路線示意、距離、時間與同行對象留下每次跑步的差異；成績不換算好感或結局分數。
- 沒有關係數字、強制倒數、固定左右道德方向。文字可直接顯示全文，鍵盤與滑鼠均可操作。

## M2 再驗證

重訪幾個夜晚，讓共同話題、承諾與角色自己的安排產生延續。先做少量有內容的事件，不先擴充日常經營數值。守約、改約與補救都可能有完整內容；關係變化依具體經歷，而非為固定結局補做罪狀。

目前舊 MainRoom 的四個每日行動只屬於既有原型，新版序章尚不接入。

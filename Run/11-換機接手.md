# 換機接手｜2026-09-11 更新

目前停在 **M1〈第一晚，真的被接住〉**。這一晚已完整可玩；M2 與後續章節有綱要，尚未製成遊戲。

## 明天開啟

1. 在另一台的 `cloud-use` 儲存庫切回 `main`，執行 `git pull --ff-only origin main`。
2. 使用 Godot **4.6.3** 開啟 `Run/game/project.godot`，等素材匯入後按 F5。
3. 也可把 Godot 執行檔拖到 `Run/開始遊戲.bat` 上；之後若想直接雙擊，將環境變數 `GODOT_EXE` 設為該執行檔的完整路徑。啟動檔會自動準備素材。

專案、腳本、人物與場景素材都在儲存庫內。玩家閱讀進度與 Alive 按讚／收藏存在本機 Godot 的 `user://first_evening_v1.json`，不隨 Git 移動；若只接續開發，直接開新局即可。
